# Implementation-plan status

The dated files in this directory are **historical execution blueprints** for MC_AI_Player. Their checkbox state records how the plans were originally written and is not the authoritative source of current repository completion or release readiness.

For current status, use the repository root `README.md` and concrete validation evidence. In particular:

- implemented code may exist even when an older plan still shows unchecked steps;
- an implemented or automated-tested component is not automatically live-E2E validated;
- pending release gates must remain pending until their required evidence exists;
- merging the pre-release runtime to `main` does not by itself satisfy the v1 release or DC_BOT integration gates.

Do not rewrite historical plan checkboxes merely to make them look current; preserve them as design/execution records and keep present-tense status in the root README.
